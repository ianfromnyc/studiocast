# Contributing

## Ground rules
- Be respectful (see CODE_OF_CONDUCT.md).
- Keep PRs small and focused.
- Prefer issues that map to an existing milestone.

## Build & run (Ubuntu 22.04)
See README.md.

## Formatting

Run:

```bash
./scripts/format.sh
```

CI will check formatting.

## Commit style
- Imperative mood: "Add X", "Fix Y"
- Include a short rationale in the PR description.
